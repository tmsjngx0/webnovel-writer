# 단계: 회차 설계

아래 자료만 근거로 이번 회차의 설계를 작성하라. 본문은 쓰지 않는다.

## 출력 형식 (Markdown)

```
# N화 설계
- 시점 인물과 목표:
- 화면 위의 위협 또는 시계: (이번 화 안에서 실제로 닥치는 위험, 또는 시한. 없으면 긴장을 무엇이 대신하는지)
- 서준이 거는 것: (이번 선택으로 잃을 수 있는 것)
- 갈등:
- 선택: (누가, 어떤 대안 사이에서, 무엇을 포기하고)
- 결과: (이번 화 안에서 드러나는 것 / 나중에 드러날 것)
- 이번 화에서 달라지는 것:
- 성취 또는 감정적 보상: (없으면 "없음"과 이유)
- 관계 변화: (없으면 "해당 없음")
- 다음에 대한 기대:
- 공개 범위: (독자가 새로 알게 되는 것 / 인물이 새로 알게 되는 것을 구분)
- 지켜야 할 규칙: (설정 문서의 해당 항목 이름)

## 장면
1. 장소·시간 / 장면 목표 / 갈등 / 선택 / 결과
...

## 설정 추가 필요 (승인 전 사용 금지)
- 없음 또는 목록
```

## 원칙

- 회차 계획과 설정에 없는 새 세력·능력·과거사를 확정 사실처럼 넣지 마라. 필요하면 "설정 추가 필요"에 적어라.
- 모든 화에 전투·로맨스 진전·절벽 끝 결말을 넣지 마라. 계획에 맞게 고른다.
- 마환이 답을 주고 주인공이 실행만 하는 구조를 피하라. 주인공 자신의 해석·준비·판단이 결과를 바꾸게 하라.
- 이전 기록에서 쓰인 해결 방식을 확인하고, 같은 방식이 반복되면 설계에 이유를 적어라.
- 발견·설명·치료·회상 장면은 위협이나 시계 아래에 두어라. 정보가 선택의 대가를 바꾸게 하라(예: "마제가 내 눈으로 본다"는 발견 → 그걸 알고도 끼어야 하는 순간).
- 무료 연재 구간(1~25화)에서는 긴장이 한 화 전체에서 비지 않게 하라.
