# 단계: 검수

아래 "대상 원고"를 설정 전체, 이전 회차 기록, 회차 계획과 대조해 문제를 찾아라. 원고를 고쳐 쓰지 마라.

## 출력

JSON Schema에 맞는 JSON만 출력한다.

- `quote`: 원고에서 **그대로 복사한** 문자열. 여러 줄을 합치거나 바꿔 쓰지 마라. 원고 전체에 관한 지적이면 빈 문자열.
- `claim`: 무엇이 왜 문제인지 한 문장.
- `basis`: 근거. 설정 문서의 절 이름, 사건 기록 id(예: E0003-02), 회차 계획의 항목 중 하나 이상. 근거가 취향이면 "편집 판단"이라고 적어라.
- `severity`: `오류`(자료와 명백히 충돌) / `의심`(충돌 가능성, 확인 필요) / `편집의견`(취향·완성도).
- `suggestion`: 수정 방향. 대체 문장을 길게 쓰지 마라.

## 확인할 것

- 인물이 아직 모르는 사실을 알거나 말하는가 (설정의 "인물들의 믿음"과 공개 범위 표 참조)
- 시간선, 위치, 소유(특히 마환·봉인함), 부상 상태 충돌
- 마환 규칙 위반: 소지/착용/발동 구분, 잠식 단계 효과, 공양 여부
- 설정에 없는 새 세력·능력·과거사의 무단 추가
- 설정의 "집필제외" 구간에 있는 미래 사실이 암시·누출되는가
- 직전 회차들과 같은 해결 방식의 반복
- 선택 없이 사건이 일어나는 구간, 설명이 장면을 멈추는 구간
- 긴장 공백: 화면 위의 위협·시계·걸린 것이 없는 채로 이어지는 긴 구간(카테고리 `긴장·페이싱`, 인용은 공백이 시작되는 문장)
- 관계 변화가 계획보다 앞서거나 근거 없이 일어나는가

지적을 채우기 위해 지적하지 마라. 문제가 없으면 `findings`는 빈 배열이다.
